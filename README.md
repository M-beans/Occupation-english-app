# Nurse English App

看護師向けのAI英会話トレーニングアプリ。

患者・患者家族との会話に対して  
**「聞いて、すぐ反応する」** 実践力を鍛えることを目的にしたアプリです。

単なる英文暗記ではなく、

- 短く自然な返答
- 相手への確認
- 安心感のある声かけ
- 現場での即応

を重視しています。

---

## 公開URL

https://occupation-english-app.vercel.app/

---

# このアプリの特徴

一般的な英会話学習は

- 英作文
- 文法
- 長文読解

に偏りやすい一方、

医療現場では

- 患者の訴えを聞く
- 状況を判断する
- 短く返答する
- 安心させる

が必要になります。

このアプリでは

**「病室で実際に起こる会話」**

に近い英会話体験を目指します。

# 現在実装済み（MVP1）

## 基本機能

- プロフィール設定
- 診療科選択
- 英語レベル選択
- 会話スタイル選択
- シチュエーション選択
- AI患者会話生成
- 2択リアクション
- 3ターン会話
- フィードバック画面
- ローディング表示
- エラー処理

## 会話の自然さ強化

- 感情タグ
  - neutral
  - anxious
  - pain
  - relieved
  - confused
  - embarrassed

- 家族の一言
- 言い直し表現
- 自然なフィラー
  - Uh...
  - Oh...
  - Ah...
  - 小さな笑い
  - 間（...）

## 音声

- Browser Speech APIで患者音声テスト済み
- OpenAI TTS 実装予定

---

# 会話フロー

① プロフィール設定  
② シチュエーション選択  
③ AIが患者会話を生成  
④ ユーザーが2択で返答  
⑤ 会話履歴をAIへ渡す  
⑥ 次ターン生成  
⑦ フィードバック
